# Knowledge Gap Intelligence Platform — Frontend (Module 1)

React + Vite frontend for Authentication & Role-Based Access Control.

## Setup
```bash
npm install
npm run dev
```
Opens at http://localhost:5173

**Important:** Make sure the Spring Boot backend is running on port 8080 first (`.\run-dev.bat` in the backend folder).

## Pages
- `/login` — Sign in
- `/register` — Create account
- `/dashboard` — Profile overview (any logged-in user)
- `/admin` — User & role management (System Administrator only)
